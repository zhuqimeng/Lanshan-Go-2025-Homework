# go组 3,4-Lesson 联合作业

*ps：第三节课当时没想到什么好的设计做，现在学了第四节课打算结合两次课的知识创作一个小游戏。*


### 游戏概念：

游戏名为**餐厅**。

玩家经营一家餐厅，需要接待顾客、烹饪食物、收取费用，并升级餐厅设施。

由于是命令行游戏，我们用简单的文字和选择菜单来呈现。

### 基本功能：

显示餐厅状态（资金、顾客队列）

顾客随机到来，并点餐

厨房烹饪需要时间，同时可以处理多个订单（有上限）

上菜，顾客离开并支付费用

升级厨房（增加同时烹饪数量）

随机事件（例如VIP顾客给予更多小费，或者顾客投诉等）

我们将使用一个循环来表示游戏的每一天（或者每一个时间单位）。

在每个周期内，玩家可以选择操作（如升级、查看状态）或者继续。

为了更简单，我们可以做成自动模拟，玩家只需要做升级决策。

### 数据结构：

餐厅：资金、厨房等级、当前顾客队列

顾客：订单（食物类型、支付金额）

### 游戏流程：

初始化餐厅

每个时间周期：

a. 随机生成新顾客（如果队列未满）

b. 处理厨房烹饪（减少剩余时间，完成后上菜）

c. 显示状态和菜单选项：升级、下一个周期、退出

我们简化烹饪过程，每个订单需要固定的烹饪时间，厨房一天烹饪的数量由厨房等级决定。
